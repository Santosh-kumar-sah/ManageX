# ManageX Architecture Decision Records (ADRs)

This directory contains records of significant architectural, technical, and security decisions made during the design and development of ManageX.

## Decision Log Summary

See [`decision-log.md`](file:///d:/manageX/docs/decisions/decision-log.md) for the active log of architectural decisions, statuses, and rationale.

## ADR Format
Each ADR adheres to:
- **Status:** Proposed / Accepted / Rejected / Superseded
- **Context:** Problem statement, constraints, and PRD references
- **Decision:** The chosen design or architecture
- **Consequences:** Positive, negative, and neutral trade-offs
- **Security Implications:** Threat model impact and testing strategy
